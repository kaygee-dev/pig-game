# 🎲 Pig Game

A simple two-player dice game built with **HTML**, **CSS**, and **JavaScript**. This project was created to practice JavaScript fundamentals such as DOM manipulation, event handling, state management, and game logic.

## 📖 About

Pig Game is a turn-based game where two players compete to reach **100 points** first.

During a player's turn:

- Roll the dice to earn points.
- Every roll (except a 1) is added to the player's current score.
- Rolling a **1** ends the turn and resets the current score to **0**.
- Press **Hold** to add the current score to the total score and pass the turn to the next player.
- The first player to reach **100 points** wins the game.

## 🎮 How to Play

1. Click **Roll Dice**.
2. Keep rolling to increase your current score.
3. If you roll a **1**, your turn ends and your current score is lost.
4. Click **Hold** whenever you want to save your current score.
5. The first player to reach **100 points** wins the game.
6. Click **New Game** to start over.
